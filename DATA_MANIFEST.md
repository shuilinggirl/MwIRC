# Data manifest and local path setup

Raw imaging data are not copied into this release directory. They remain under
their original access conditions. Derived tables should be shared only when the
source dataset license permits redistribution.

## Participant datasets

| Dataset | Paper 1 role | Paired modalities | Final sample represented in frozen results | Local path setting |
|---|---|---|---:|---|
| AUF | discovery and high-resolution analysis; DK68 harmonized analysis | resting-state fMRI and FDG-PET | 18 after time-series QC | `config/information_specific_mwc.yaml` and `config/harmonized_dk68_replication.yaml` |
| Monash | independent DK68 replication | resting-state fMRI and FDG-PET | 27 | `config/harmonized_dk68_replication.yaml` |
| QNLD | large independent DK68 replication | resting-state fMRI and FDG-PET | 194 (43 younger, 151 older) | `dataset.local_root` in `config/qnld_consequence.yaml`; `edge_inputs.qnld_prepared_root` in `config/cognitive_complementarity_replication.yaml` |

The primary harmonized analysis requires, for each retained participant:

- an explicitly identified participant ID;
- regional resting-state fMRI time series in canonical DK68 order;
- regional FDG values from the same participant and visit;
- sufficient valid samples to construct exactly 294 lagged transitions;
- the cohort-specific QC records used to define the frozen analysis set.

## Making local configs portable

The frozen YAML files preserve the paths used for the reported analyses and may
therefore contain workstation-specific locations. Before rerunning on a new
machine, copy each required YAML file to a new local filename and change only the
dataset/atlas path fields. Keep all analysis parameters unchanged and pass the
new file through the corresponding `--config` option.

Example:

```bash
cp config/qnld_consequence.yaml config/qnld_consequence.local.yaml
# Edit dataset.local_root and output/inventory paths only.
python scripts/run_qnld_replication_and_consequence.py \
  --config config/qnld_consequence.local.yaml --skip-full-length
```

Do not commit `.local.yaml` files if they disclose private filesystem paths.

## Files excluded from a public archive

- raw PET, fMRI, T1-weighted MRI, and identifiable metadata;
- ADNI downloads and credentials;
- workstation-specific path configs;
- intermediate registration images unless redistribution is explicitly allowed;
- old exploratory result directories not used by the manuscript.

The public deposit should contain de-identified derived metrics, canonical ROI
metadata, allowed spatial-null arrays, source code, environment files, and the
SHA-256 inventory generated by `paper1_pipeline.py snapshot`.
